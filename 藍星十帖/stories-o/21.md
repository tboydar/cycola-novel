# 番外二十一：雲端遷爐

十月十七日那天，霧語山城的雨下得很細，細得像焙籠上飄起來的茶末。

Cy老師是在晨間卜卦之後看到那封信的。lifeOS 的字型一行一行浮上來，數位學堂的教學站寄件人那一欄，寫著平台方的名字。信很客氣，客氣得讓人心裡發涼：近期發生兩起資安事件，十二月一日起共享叢集暫停服務，十二月三十一日全面停止營運。換句話說，他們架了三年的教學站——戴罔市阿嬤四十年焙茶筆記的數位課程、村裡年輕人線上學看火的那個站——賴以為生的那朵雲，要散了。

他盯著螢幕看了很久，然後做了一件工程師的本能會做的事：先去換鑰匙。

「資安事件之後搬東西，要先換鎖。」晚上八點，戴粉厚從中部山線騎機車上山，雨衣還滴著水，Cy老師把一杯熱茶推過去，「東西還沒搬，鑰匙先輪換一輪。跟茶園淹水一個道理，先排水，再談收成。」

粉厚點點頭。他話少，但手腦都快。半年多前他接下了藍鵝，那台銀灰色、左下角有一道明燒痕的 Mac mini，現在就擺在厚茶行的閣樓裡，旁邊是阿嬤留下來的那箱受潮筆記。今晚他把筆電帶上山，接上學校辦公室的螢幕，打開終端機，叫出了 pi agent。

pi agent 是一隻命令列裡的 AI 助手，Cy老師管它叫「新來的實習生」。不會泡茶，不會看火，但盤點起家當來又快又誠實。粉厚敲了幾行指令，實習生就把教學站的身家全列了出來：一個網站本體、一座資料庫、一個放影片課程的儲存空間、三支排程任務、還有七八把散落在各處的金鑰——有些連Cy老師自己都忘了它的存在。

「原來我們這麼有錢。」粉厚看著清單，難得說了句玩笑。

「有錢人家的鑰匙才多。」Cy老師說，「一把一把換，換完記得把舊的作廢，不要留退路給陌生人。」

兩個人就著辦公室的燈，一把一把輪換。焙焙貓——那隻不知從哪年起接管了學校辦公室的虎斑貓——跳上桌，在鍵盤旁邊趴定，尾巴一甩一甩，像在監工。每換好一把，牠就用鼻子碰一下螢幕邊緣，彷彿驗收。

金鑰換完，換備份。Cy老師在白板上寫下：三份副本、兩種媒體、一份異地。

「三、二、一。」粉厚念著，忽然說，「我阿嬤也是這樣欸。」

Cy老師挑眉。

「她的手寫筆記，正本一箱，我阿公以前影印過一份放神明廳後面，她自己的記憶是一份。」粉厚說，「後來神明廳那份淹水先爛掉，正本去年也受潮。剩下她腦子裡那份……跟著她走了。」他頓了頓，「所以我才要做這個教學站。三份，不能再少。」

辦公室安靜了一會兒，雨聽起來更細了。Cy老師沒接話，只是指揮實習生把資料庫匯出、網站打包、影片同步到兩個不同的去處。進度條一格一格走，像焙籠裡慢慢轉色的茶葉。

備份跑著，兩人開始討論落腳處。pi agent 很稱職，把幾條路都攤開在終端機上，用最樸素的字排給他們看。

有兩家國外的 VPS，一個月三塊半到四塊美金，便宜得像巷口麵攤加一顆滷蛋，機器是你的，什麼都要自己裝。有一家介面最像現在這家的，搬家最省事，價錢貴上好幾倍。至於兩家最大的雲端巨頭，功能強大到可以開航空母艦，但帳單是出了名的驚奇箱——今天忘了關一個開關，月底寄來的數字能讓人半夜驚醒。還有一家做加速網路的，在島上就有節點，學生連線會很快，但放資料庫這種重活不太是它的本行。

「最便宜那個。」粉厚幾乎沒猶豫。茶鄉出來的人，對錢有身體記憶。

Cy老師卻搖搖頭，不急著反駁，反問：「你焙茶的時候，是先問火要多大，還是先問這批茶要做成什麼樣？」

粉厚怔了一下。「……先看茶。」

「對啊。」Cy老師往椅背一靠，「先問目的，再問預算——跟焙茶一樣。這個站的目的是什麼？不是賺錢，不是流量，是讓村裡的年輕人有一個穩定的地方學看火。一年三百六十五天，不能說倒就倒，維護起來不能太複雜，複雜到我們哪一個感冒了，站就沒人顧。」

粉厚低頭看著終端機，一行一行重新讀。過了一會兒，他說：「便宜的 VPS 是毛胚屋，什麼都自己來。可是如果加一層管理軟體……」

「開源的管理台。」Cy老師接口，「自己家的機器，配上自助部署的那一層，介面學那種大平台的樣子，骨子裡鑰匙還是在我們手上。一個月四塊錢，加上我們兩個人的手感。」

「一個月四塊。」粉厚笑了，「比一包焙火的炭還便宜。」

決定下得比想像快。接下來是搬家本身：租機、裝系統、把備份一層一層鋪回去、讓實習生把每個服務重新接上。pi agent 幹活幹得勤，偶爾會問一些笨問題，笨得很真誠，像真正的實習生那樣。粉厚負責盯資料庫匯入，一筆一筆對，對到阿嬤民國七十四年那一爐「火足、陰雨、心緒平」的紀錄出現在新站的頁面上時，他的手指在鍵盤上停了很久。

最後是切 DNS。午夜十二點，Cy老師把 TTL 調低，等舊站的火熄、新站的火起。那幾分鐘辦公室裡沒人說話，焙焙貓睜著眼睛，尾巴也不甩了。粉厚後來說，那感覺很像焙茶出焙的前一刻——你能做的都做了，剩下的交給火候。

重新整理。頁面亮起來。阿嬤的筆記、村裡孩子的課程、那句「火候、天氣、心緒」，全部都在，只是換了一朵雲住。

「好了。」Cy老師關掉終端機，去泡了兩杯茶。窗外藍色的月亮掛在雨後的山稜上，藍鵝雖然不在這間辦公室了，但 lifeOS 還在每台機器上跑著同樣的字型。

粉厚捧著茶杯，忽然說：「老師，平台倒了，我們也只是把東西搬走而已。總有一天這個 VPS 也會倒吧。」

「會啊。」Cy老師喝了一口茶，「平台會倒，手藝跟著人走。你阿嬤的筆記爛掉之前，你先學會了她的手；雲關門之前，我們學會了怎麼搬家。鑰匙換過了，備份三份了，看火的眼睛還在——」

他指指自己的眼睛，又指指粉厚的。

「站放哪裡，其實都差不多。端得起鍋鏟也端得起念頭的人，在哪一朵雲底下，都焙得出茶。」

焙焙貓「喵」了一聲，算是散會。粉厚收拾好筆電，穿上還沒全乾的雨衣，走進山城的夜裡。機車發動的聲音遠去之後，Cy老師回到螢幕前，在 lifeOS 的日誌裡敲下這一天的記事。

他本來要關機的，卻看見那個沒寫進任何文件的模組——緣分排程器——悄悄在日誌末尾加了一行排程：下個月初，茶鄉，備份演練，出席者二人一貓。

Cy老師笑了笑，沒有刪它。雲會來，雲會散，排程器比他更早知道下一爐火在哪裡。
