## 五、事件與對策（供未來專案參考）

1. **平行請求上限**：平台限 2 並行 → 腳本必備 403 偵測＋指數退避。
2. **模型能力落差**：同提示詞下輸出長度 700～4,500 字浮動 → 設字數下限驗收，不足即換型重跑。
3. **端點相容性**：部分模型不支援代理端點 → 先小樣探測再派工。
4. **長文生成劣化**（助手端）：長 CJK 輸出中段亂碼 → 小檔策略、程式化拼接、派工給模型。
5. **worker 產出 bug**：IIFE 未調用導致功能靜默失效 → 產出必做結構級驗證（括號平衡、關鍵語句存在）。
6. **push 靜默失敗**：兩次遠端未更新 → 推送後必查 `ls-remote` 對照。
