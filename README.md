# 藍星十帖・Cy可樂老師傳

一座酷似台灣的星球「藍星」，一位會舉重、懂佛學、家傳神秘學、用 Mac mini 建 lifeOS 的老師——
以及一場關於二手 Mac mini 的現代傳缽。

- **主線十帖**：10 篇連環短篇，從雨城的木魚與開機聲，到暴雨夜的傳缽
- **外傳二十一帖**：21 篇番外，雜貨店老闆娘、店貓、客運司機、藍鵝自己的自述，咖啡烘焙帖與雲端搬家帖
- **封面插圖**：水彩風，每篇一張
- **3D 世界**：主線十帖各有一個可環繞探索的立體場景，藏著四十段記憶等待點亮

31 篇全數由 AI 語言模型共筆生成，人類擔任世界觀設計與編輯。
